# SkillSwap — 3D Real-People Design

A five-page, responsive, frontend-only informational website concept.

## Pages
- `index.html` — homepage with a CSS 3D globe, photo cards and floating skill labels
- `about.html` — concept, challenge, values and vision
- `how-it-works.html` — four-step exchange process and fictional interactive example
- `features.html` — proposed features and benefits
- `faq.html` — FAQs and a frontend-only contact form demo

## Run locally
Extract the ZIP and open `index.html` in a browser. For a better local development experience, open the folder in VS Code and use Live Server.

## Publish with GitHub Pages
Upload the complete contents of this folder to the root of a GitHub repository. Go to **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.

## Important notes
- This is an informational website. It does not have a backend, real user accounts, a database, real matching or message delivery.
- The sample people and exchange are illustrative. The photographs are remote stock photos loaded from Unsplash and require an internet connection.
- This site is a new visual implementation inspired by the requested photographic, 3D direction; it is not an exact pixel-for-pixel copy of the reference image.
